# 后记

动笔之初，并未意识到首先要做到的是能够清清楚楚地讲一个故事，天马行空地发泄了一番表达冲动之后，突然发现没办法写下去了，而已经写出来的章节也都支离破碎，不知所云。

后来之所以能继续下去，是因为四月的时候，豆瓣发起了一拨新的长篇连载拉力赛。当时想都没想就报了名，盼望着能蹭个流量。因为光写没人读，根本得不到可供改进的反馈。实际效果就呵呵了，在大V统治社交网络的时代，想让普通个体的声音被听到简直是前所未有的困难。所以，直到如今，我都怀念天涯论坛的那个时代，至少每个人都有着平等的发声机会。不过，积极因素也是有的，比如紧迫的更新要求逼着我终于完成了它。

后面的时间主要是在修改，核心仍然是努力讲好这个故事，字数从起先的十万增加到十二万，而实际上依然捉襟见肘，是不是足够让人读懂，心里其实没有一点数。

故事的人物关系有两条线，陆一鸣、夏敏（米娅）和陈柳一条在明面上，“熊”、陆楠（萧夫人）和萧林那条藏在后面。在陆一鸣身上笔墨花得最多，但故事里他并不是我想关注的人，这个人平凡而毫无性格，正如我们身边最常见的那种人：他们自私、没有担当、优柔寡断，可他如果碰巧长得高大俊朗，仍旧很容易得到女人倾心，又如果机缘巧合把他扔到了改变世界的十字路口上，他依然有可能会做出一些惊人的决定。

我以为故事真正的主角应该是米娅和萧夫人，她们细腻而纯净的心灵是才我努力想展现给读者的。

萧林于二零二一年元旦
